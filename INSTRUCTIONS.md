# Инструкция по установке и запуску

## 1. Требования

- Google-аккаунт с доступом на редактирование к таблице «Справочник источников».
- Первая вкладка таблицы должна называться так, чтобы **первой по счёту** (`ss.getSheets()[0]`) была именно вкладка с исходными данными, со столбцами (порядок не важен, важны точные названия заголовков в первой строке):
  `Тип`, `Категория`, `Раздел`, `Источник`, `utm_source`, `utm_medium`, `Аналитика (новое название)`, `ЖК. Источник`, `Телефон`, `Комментарий`, `ID Битрикс24`, `UTM_term`, `Проект в Колтач`, `URL`, `UTM_Campaign ...`, `URL с UTM`, `Calltouch / пул номеров`.

## 2. Установка кода в таблицу

1. Откройте таблицу → **Расширения → Apps Script**.
2. В файле `Код.gs` (переименуйте/используйте как `Code.gs`) удалите содержимое по умолчанию и вставьте код из [`Code.gs`](./Code.gs) этого репозитория.
3. Создайте новый файл: **File → New → HTML**, назовите его ровно **`Index`** (расширение `.html` Apps Script добавит сам). Вставьте содержимое [`Index.html`](./Index.html).
4. В начале `Code.gs` найдите строку:
   ```javascript
   var SECRET_TOKEN = 'ЗАМЕНИ_МЕНЯ_НА_СВОЙ_ПАРОЛЬ';
   ```
   Замените на свою короткую строку **в кавычках**, например:
   ```javascript
   var SECRET_TOKEN = 'sever2026';
   ```
   Токен нужен только для необязательного режима `?action=rebuild&token=...`, вызываемого вручную из браузера — на работу формы он не влияет.
5. Сохраните проект (Ctrl+S).

## 3. Первый запуск (создание вкладок)

1. В выпадающем списке функций вверху редактора Apps Script выберите `rebuildRelationalTabs`.
2. Нажмите ▶️ **Выполнить**.
3. При первом запуске Google запросит разрешения — подтвердите (скрипт работает только внутри этой таблицы, доступ к внешним сервисам не требуется).
4. После выполнения в таблице появятся вкладки: `Sources`, `Phones`, `Обозначения`, `Резервные_UTM_term`.
5. На вкладке `Резервные_UTM_term` появится 5 стартовых значений — пополните список вручную (просто допишите новые `utm_term` в столбец A, ничего больше трогать не нужно).

## 4. Публикация веб-формы

1. **Deploy → New deployment**.
2. Type: **Web app**.
3. Execute as: **Me**.
4. Who has access: **Anyone with the link**.
5. **Deploy**, разрешите запрошенные права.
6. Скопируйте URL, заканчивающийся на `/exec` — это и есть ссылка на форму создания источников. Раздайте её нужным сотрудникам.

### Обновление после правок кода

Любое изменение `Code.gs` или `Index.html` требует нового деплоя, иначе форма продолжит работать на старой версии:

**Deploy → Manage deployments → (значок карандаша у деплоя) → Version: New version → Deploy.**

## 5. Повседневное использование

- **Создать новую UTM-ссылку** — откройте ссылку веб-приложения, заполните форму, нажмите «Создать запись». Новая строка допишется в конец «Справочник источников», `Sources`/`Phones`/`Обозначения` пересоберутся автоматически.
- **Пересобрать таблицы вручную** (если правили исходный лист напрямую, а не через форму) — снова запустите `rebuildRelationalTabs` из редактора Apps Script.
- **Пополнить резерв `utm_term`** — впишите новые значения в столбец A вкладки `Резервные_UTM_term`, статус проставится сам.

## 6. Как добавлять новые справочные значения

Если появляется новое значение в исходных данных (новый `Источник`, `Аналитика`, ЖК/проект или РА), словари в `rebuildRelationalTabs()` внутри `Code.gs` нужно дополнить вручную:

| Словарь | За что отвечает | Пример добавления |
|---|---|---|
| `sourceUtmMap` | код для `Источник utm` | `'03.01 Соцсети': 'social'` |
| `analitikaUtmMap` | код для `Аналитика utm` | `'02.05 Конверт': 'envelope'` |
| `zhkUtmMap` | код для `Проект utm` | `'Новый ЖК': 'new'` |
| `raUtmMap` (в форме — `RA_UTM` внутри `Обозначения`) | код для `РА_utm` | `'Новое АРА': 'new'` |
| `utmSourceMediumMap` | `utm_medium` по значению `utm_source` | `'press_envelope': 'qr'` |
| `ALLOWED_DOMAINS` | домены, которые форма готова обогащать UTM | `'new-domain.ru'` |

После правки — сохраните и повторно запустите `rebuildRelationalTabs` (для словарей `Обозначения`) и передеплойте веб-приложение (для `ALLOWED_DOMAINS`, если правился этот файл после последнего деплоя).

## 7. Уведомление о нехватке резерва

Функция `checkReserveAndNotify()` автоматически вызывается после каждой отправки формы. Если свободных `utm_term` в `Резервные_UTM_term` меньше порога (по умолчанию 5, ячейка `E2` на этой вкладке), на почту владельца скрипта (`Session.getEffectiveUser().getEmail()`) уходит письмо. Порог можно поменять прямо в ячейке `E2`, код трогать не нужно.

## 8. Диагностика типичных проблем

| Симптом | Причина | Решение |
|---|---|---|
| `#ERROR!` в формулах на вкладках `Sources`/`Phones` | Локаль таблицы требует `;` вместо `,` в формулах | Уже исправлено в текущей версии кода (разделитель определяется автоматически по локали) |
| `ReferenceError: ... is not defined` в строке с `SECRET_TOKEN` | Токен вписан без кавычек | Оберните значение в одинарные/двойные кавычки |
| Не получается вызвать `/exec?action=rebuild&token=...` из внешнего скрипта/бота | `script.google.com` закрыт для автоматического доступа в `robots.txt` | Запускайте пересборку вручную из Apps Script или открывайте ссылку в обычном браузере — это ограничение не касается формы, которую открывает человек |
| Форма не находит вкладку `Обозначения`/`Резервные_UTM_term` | Не был выполнен первый запуск `rebuildRelationalTabs` | Выполните шаг 3 инструкции |
