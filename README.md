# UTM Source Manager

Google Apps Script надстройка над Google Таблицей **«Справочник источников»**: превращает плоскую таблицу маркетинговых источников (с дублирующимися строками) в набор связанных таблиц (в духе реляционной БД) + веб-форму для создания новых UTM-ссылок без риска задвоить `utm_term` или испортить данные.

## Проблема, которую решает проект

Исходная таблица «Справочник источников» — один плоский лист, где одному `utm_term` могло соответствовать несколько телефонов (колл-трекинг) и/или несколько URL. Из-за этого приходилось дублировать всю строку целиком ради одного отличающегося значения, справочник разрастался дублями и терял целостность.

## Что делает проект

1. **Нормализует данные** — разносит исходный лист на связанные таблицы:
   - `Sources` — один `utm_term` = одна строка (первичный ключ), включая URL (1:1);
   - `Phones` — телефоны, привязанные к `utm_term` (1:N, внешний ключ);
   - `Обозначения` — справочник допустимых значений и их коротких utm-кодов (Тип, Раздел, Источник, Аналитика, ЖК/Проект, РА) с вычисляемыми парами `*_utm`;
   - `Резервные_UTM_term` — пул свободных `utm_term` про запас, с автостатусом «Свободен/Использован» и уведомлением при нехватке.
2. **Даёт веб-форму** для создания новой записи источника: каскадные выпадающие списки (Раздел → Источник → Площадка), автоматический подбор `utm_source`/`utm_medium`, автосборка `UTM_Campaign`, выдача `utm_term` из резерва, проверка домена URL по белому списку, запись новой строки в конец «Справочник источников» и автоматическое обновление `Sources`/`Phones`.

## Технологии

- Google Sheets + Google Apps Script (JavaScript / V8 runtime)
- HTML/CSS/vanilla JS для формы (`google.script.run` как мост к серверу)
- Без внешних зависимостей, без сервисных аккаунтов, без стороннего хостинга

## Ограничения текущей версии

- Работает только через ручной запуск (`rebuildRelationalTabs`) или через форму — нет автоматического триггера по расписанию.
- Резерв `utm_term` пополняется вручную (добавлением строк на вкладку `Резервные_UTM_term`).
- Телефоны через форму не выдаются — только utm-метки (`Категория` всегда `"без телефона"`).
- Списки кодов (`sourceUtmMap`, `analitikaUtmMap`, `zhkUtmMap`, `raUtmMap`, `utmSourceMediumMap`) — статичные словари в коде, при появлении новых значений их нужно дополнять вручную (см. INSTRUCTIONS.md).
