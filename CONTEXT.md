# Контекст проекта

## Кто и зачем это использует

Отдел маркетинга девелоперской компании ведёт справочник рекламных источников для нескольких жилых комплексов (ЖК) и офисов: Айрис, Дабл-Дабл, Диус (в т.ч. коммерция), Литературный, Смородина, Эхо леса, а также точки в Екатеринбурге, Москве, Тюмени и общий бренд «Север». Каждый источник трафика (площадка размещения объявления/QR-кода/лифлета) должен быть помечен уникальной utm-меткой, чтобы отследить, откуда пришло обращение — по телефону (колл-трекинг) или по клику на сайт.

## Исходные данные — «Справочник источников»

Один лист Google Таблицы, где каждая строка — один канал привлечения. Ключевые столбцы:

| Столбец | Смысл | Пример |
|---|---|---|
| Тип | Верхнеуровневый тип обращения | `Прямые` |
| Категория | Есть ли колл-трекинг у этой записи | `Звонки` / `без телефона` |
| Раздел | Крупная группа каналов | `01. Интернет`, `02. Оффлайн` |
| Источник | Подгруппа внутри раздела | `01.02. Базы недвижимости`, `02.05 Печатная продукция` |
| utm_source | Код площадки для UTM | `base_avito`, `press_catalog` |
| utm_medium | Тип размещения для UTM | `cpa`, `print`, `qr` |
| Аналитика (новое название) | Человекочитаемое имя площадки | `01.02 Авито`, `02.05 Каталог` |
| ЖК. Источник | Для какого ЖК/офиса заведён источник | `Айрис`, `Север` |
| Телефон | Номер для колл-трекинга (если есть) | `73452578676` |
| UTM_term | Уникальный идентификатор источника (**ключ**) | `596\|` |
| URL | Целевая посадочная страница (если есть) | `https://sever-group.ru/complexes/airis` |
| UTM_Campaign | `РА\|Проект\|название_год_месяц` | `svr\|sever\|catalog_13_04` |
| URL с UTM | Готовая ссылка с проставленными метками | `https://.../?utm_source=...&utm_term=596\|` |
| Calltouch / пул номеров | Человекочитаемый путь до источника | `01.02. Базы недвижимости / Авито / Айрис` |

## Проблема исходных данных

`UTM_term` задуман как уникальный ключ, но:
- у одного источника может быть **несколько телефонов** (разные номера колл-трекинга ведут на один и тот же `utm_term`);
- у одного источника может быть **несколько URL** (например, один QR-код печатается на разных материалах, ссылающихся на разные страницы, но с одной меткой).

Из-за этого строки с одинаковым `UTM_term` дублировались целиком, чтобы вместить разные телефоны/URL — это ломало идею уникального ключа и усложняло любой анализ (например, посчитать число уникальных источников через `COUNTIF` становилось невозможно без дополнительной чистки).

## Обнаруженные в данных примеры дублей

- `598|` — один источник (Смородина, Авито), два телефона.
- `3651|`, `3589|`, `841|` — по одному источнику с двумя разными URL.

## Принятая модель данных

Решение: развести сущности по количеству значений на один `UTM_term`:

- **1 к 1** (URL, все базовые атрибуты источника) → остаются в одной строке **Sources**.
- **1 ко многим** (телефоны) → выносятся в отдельную таблицу **Phones** со своим `phone_id` и внешним ключом `utm_term`.

Подробное обоснование каждого решения — см. [DECISIONS.md](./DECISIONS.md).

## Что такое «Обозначения» и «Резервные_UTM_term»

- **Обозначения** — вручную/автоматически поддерживаемый справочник допустимых значений (что показывать в выпадающих списках формы) и их коротких кодов для сборки `utm_source`/`utm_medium`/`utm_campaign` по правилам, которые уже используются в реальных данных компании.
- **Резервные_UTM_term** — заранее выделенный пул `utm_term`, который назначается автоматически при создании нового источника через форму, чтобы исключить коллизии ключей и ручной подбор следующего свободного номера.

## Действующие правила именования (актуальны на момент написания)

- `utm_source` = `[Источник_utm]_[Аналитика_utm]`, например `base_avito`.
- `utm_medium` определяется по `utm_source` (см. `utmSourceMediumMap` в коде).
- `UTM_Campaign` = `[РА_utm]|[Проект_utm]|[название]_[год]_[месяц]` — где название кампании вводится вручную одним словом на латинице, год/месяц берутся на момент создания записи.
- `URL с UTM` = `URL` + (`?` если в URL ещё нет параметров, иначе `&`) + `utm_source=...&utm_medium=...&utm_campaign=...&utm_term=...`.
