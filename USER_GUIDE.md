# Инструкция для пользователя формы

Короткая шпаргалка: что нажимать, когда нужно добавить новую **ссылку с UTM-метками** или новый **источник по звонку**.

---

## Сценарий 1 — Добавление UTM-ссылки (без телефона)

Когда есть посадочная страница/QR-код/лифлет и нужна просто ссылка с метками.

1. **Тип обращения** — выберите значение (обычно один вариант).
2. **Категория обращения** — оставьте **«Без телефона (по ссылке)»** (это значение по умолчанию).
3. **Раздел** — выберите крупную категорию (например, «01. Интернет» или «02. Оффлайн»).
4. **Источник обращения** — список отфильтруется по выбранному разделу, выберите подходящий.
5. **Площадка размещения** — список отфильтруется по источнику, выберите конкретную площадку (например, «Авито», «Каталог»).
   - Если появилось поле **5a. Тип размещения** — у этой площадки несколько вариантов (например, `qr` и `print`), выберите нужный.
6. **Проект** — выберите нужный проект.
7. **URL** — вставьте ссылку на страницу. Протокол (`https://`) можно не писать, поддерживаются только 5 доменов компании (форма сама подскажет, если домен не тот).
8. **Ответственный за площадку (РА)** — выберите, кто отвечает за эту площадку.
9. **Кампания** — впишите одно слово латиницей (например, `catalog`) — дата подставится автоматически.
10. Нажмите **«Создать запись»**.
11. Скопируйте готовую ссылку из результата (кнопка «Скопировать ссылку») и используйте её.

**Не забудьте:** новая запись попадёт со статусом **«На модерации»** — она не появится в отчётах (`Sources`), пока модератор не одобрит и не впишет её в Колтач.

## Сценарий 2 — Добавление источника по звонку (с телефоном)

Когда номер телефона — часть колл-трекинга, ссылка не нужна.

1. **Тип обращения** — выберите значение.
2. **Категория обращения** — переключите на **«Звонки (по телефону)»**. Появится подсвеченный синим блок:
   - **2a. Телефон** — впишите номер (без пробелов).
   - **2b. Проект в Колтач** — впишите название проекта в Колтач вручную (для звонков это нужно заполнить сразу, не при модерации).
3. **Раздел → Источник → Площадка → Проект** — заполняются точно так же, как в сценарии 1 (шаги 3–6 выше).
4. **URL и Кампания** — станут полупрозрачными и необязательными. Можно оставить пустыми (это нормально для звонков — в таблице появится «нет ссылки»), а можно заполнить, если для этого звонка всё-таки есть привязанная страница.
5. **Ответственный за площадку (РА)** — выберите как обычно.
6. Нажмите **«Создать запись»**.
7. В результате увидите присвоенный `utm_term` и номер телефона (вместо ссылки).

**Не забудьте:** так же, как и со ссылками — статус **«На модерации»** до одобрения модератором.

## Полезные кнопки на форме

| Кнопка | Что делает |
|---|---|
| 📊 Открыть Справочник источников | Открывает саму Google Таблицу в новой вкладке — посмотреть исходные данные напрямую |
| 🔍 Посмотреть значения | Показывает существующие записи, подходящие под уже заполненные вами поля — полезно проверить, не создаёте ли вы дубль |
| 🌳 Структура источников | Разворачиваемое дерево: Тип → Раздел → Источник → Площадка — посмотреть все допустимые сочетания перед заполнением |
